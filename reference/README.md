# Reference material

Read-only reference copies. Nothing here is built or shipped.

## perchance-src/

Source of the "Audionook" text-to-speech app hosted at https://perchance.org/audionook,
exported by the repo owner. Third-party code with no licence stated; kept for study only.

- `*.js` — the app's `src/` modules as exported (originally `src/<name>.js`).
- `styles.css` — `src/styles.css`, extracted from `download.mhtml`.
- `rendered-page.html` — the rendered app markup from `download.mhtml` (scripts stripped by the browser).
- `app-details.txt` — a summary of `app.js`.

Not yet captured: `import.js`, `crop.js`, `syncmeta.js`, `devicePerf.js`,
`src/espeak-ng/*`, `src/README.md`, and the Perchance HTML panel.
